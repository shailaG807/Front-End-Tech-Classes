3. CSS 2D Transforms 🔄

2D transforms change the position, size, angle, or shape of an element on a flat page.

Click each button and observe what happens to the blue box.

My Box

What do these actions mean?

  • Move Right: Moves the box 100 pixels right.
  • Rotate: Turns the box by 45 degrees.
  • Increase Size: Makes the box bigger.
  • Decrease Size: Makes the box smaller.
  • Slant: Slants the box sideways.
  • Reset: Returns the box to its original shape.
